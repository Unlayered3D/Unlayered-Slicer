4  Every method

One row per method. Edit the JSON parameters and send. A row is enabled only while its method is in capabilities: most need a permission that the user turns on per slot (Preferences ▸ Advanced ▸ Web apps & services), and slicer.capabilitiesChanged re-enables rows when they do. "$handle" is replaced by the last export handle, and "$turn" by the turn below. A turn is a grouping this page defines: every call sent with the same turn is undone together by slicer.undoTurn.
